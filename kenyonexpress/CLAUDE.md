# KenyonExpress - Project Rules

## Stack
- Next.js 15 + TypeScript + Tailwind CSS
- Supabase (DB + Auth + Storage)
- Cardcom (Israeli payment processing)
- Vercel (deployment)

## Rules
- RTL direction always (Hebrew UI)
- Code in English only
- Mobile first
- Full solutions only, no skeletons
- After each feature, suggest next step
- App Router only (no Pages Router)
- Use server components by default, client components only when needed

## Project
- Israeli Super App (coupons, deals, products)
- Target market: Israel only
- Language: Hebrew
