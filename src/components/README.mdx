# KenyonExpress Design System

Welcome to the KenyonExpress component library. This guide documents all reusable UI components, their usage patterns, and design principles.

## Overview

The design system is built with:
- **React 19** with TypeScript
- **Tailwind CSS v4** for styling
- **Class Variance Authority** for component variants
- **Radix UI** for accessible primitives
- **Next.js 16** App Router

## Design Principles

### 1. Hebrew RTL Support
All components support right-to-left (RTL) text direction with logical CSS properties:
- Use `start`/`end` instead of `left`/`right`
- Use `ms-`/`me-` for margins
- Use `ps-`/`pe-` for padding
- All components render correctly with `dir="rtl"` on the root

### 2. Accessibility
Components follow WCAG 2.1 AA standards:
- Proper ARIA labels and descriptions
- Keyboard navigation support
- Color contrast ratios ≥ 4.5:1 for text
- Focus indicators visible on all interactive elements
- Semantic HTML structure

### 3. Currency & Money
All money values use **integer agorot** (1/100 of a shekel):
- `price: 9999` = ₪99.99
- Use `money.ts` utilities for all calculations
- Display via `PriceDisplay` component for consistency
- Never use floating-point for financial calculations

### 4. Consistency
- Use design tokens for colors, spacing, and typography
- Follow the Electro design system variant naming
- Maintain visual hierarchy through size and weight
- Consistent spacing with Tailwind scale

## Core Components

### Buttons

The `Button` component is the primary action element.

```tsx
import { Button } from '@/components/ui/button'

<Button variant="primary" size="md">
  צריך עזרה?
</Button>
```

**Variants:**
- `primary` - Yellow (Electro yellow) - Main CTAs
- `secondary` - Gray - Secondary actions
- `ghost` - Transparent - Minimal emphasis
- `danger` - Red - Destructive actions
- `link` - Text only - Navigation/tertiary actions

**Sizes:**
- `sm` - Small (8px)
- `md` - Medium (10px) - Default
- `lg` - Large (12px)
- `icon` - Square icon button

**States:**
- `loading` - Shows spinner
- `disabled` - Disabled state
- `loadingText` - Custom text during loading

### Form Inputs

#### Input

```tsx
import { Input } from '@/components/ui/input'

<Input 
  placeholder="הזן טקסט..."
  variant="default"
  size="md"
  type="text"
/>
```

**Variants:**
- `default` - Standard white input
- `error` - Red error state
- `success` - Green success state
- `disabled` - Disabled state

**Sizes:** `sm`, `md`, `lg`

#### Label

```tsx
import { Label } from '@/components/ui/label'

<Label htmlFor="input-id" required>
  דוא"ל
</Label>
```

**Props:**
- `required` - Shows red asterisk
- `variant` - default, error, success, muted
- `size` - sm, md, lg

### Cards

Composable card component for organizing content:

```tsx
import { Card, CardHeader, CardTitle, CardContent } from '@/components/ui/card'

<Card>
  <CardHeader>
    <CardTitle>כותרת</CardTitle>
  </CardHeader>
  <CardContent>
    תוכן הכרטיס
  </CardContent>
</Card>
```

**Subcomponents:**
- `Card` - Container
- `CardHeader` - Top section with padding
- `CardTitle` - Large title
- `CardDescription` - Subtitle/description
- `CardContent` - Main content area
- `CardFooter` - Bottom section for actions

### Price Display

Specialized component for displaying ILS prices:

```tsx
import PriceDisplay from '@/components/PriceDisplay'

<PriceDisplay 
  price={4999}
  originalPrice={9999}
  showSavingsBadge={true}
  allowHebrewNumerals={true}
/>
```

**Features:**
- Displays prices in format: ₪99.99
- Shows original price with strikethrough when on sale
- Green savings badge with discount amount
- Optional Hebrew numeral toggle
- Full RTL support

## Best Practices

### 1. Money Handling
Always use the `money.ts` utilities:
```tsx
import { shekelsFromIls } from '@/lib/money-format'
const display = shekelsFromIls(9999) // "₪99.99"
```

### 2. Images
Use Next.js `<Image>` with optimization:
```tsx
import Image from 'next/image'

<Image
  src="/image.jpg"
  alt="תיאור בעברית"
  width={400}
  height={300}
  loading="lazy"
  sizes="(max-width: 640px) 100vw, 50vw"
/>
```

### 3. Forms
Always pair inputs with labels:
```tsx
<div className="space-y-2">
  <Label htmlFor="email" required>דוא"ל</Label>
  <Input id="email" type="email" />
</div>
```

### 4. RTL Awareness
- Don't use `flex-row-reverse` for layout control
- Use logical properties (start/end)
- Test with `dir="rtl"` on root
- Mirror directional icons with `rtl:scale-x-[-1]`

### 5. Performance
- Use `loading="lazy"` for below-fold images
- Lazy load components with `dynamic()` and `ssr: false`
- Implement Suspense boundaries for async content
- Use `<picture>` for art direction
