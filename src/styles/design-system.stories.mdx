# Kenyon Express Design System

Welcome to the Kenyon Express design system documentation. This Storybook serves as the single source of truth for all UI components, design tokens, and usage patterns.

## Design Principles

Our design system is built on these core principles:

- **Hebrew-First**: All content and interactions are designed for Hebrew (RTL) language and culture
- **Accessibility**: WCAG 2.1 AA compliance across all components
- **Performance**: Optimized for fast load times and smooth interactions
- **Consistency**: Unified visual language across the entire storefront
- **Mobile-First**: Responsive design that works seamlessly across all devices

## Color System

### Primary Colors

Our primary color palette is based on the brand yellow (#fed700) with semantic color families for different use cases.

#### Brand Yellow (Primary)
- **Base**: #fed700
- **Hover**: #fedd26
- **Usage**: Call-to-action buttons, highlights, primary brand elements

#### Semantic Colors
- **Success**: Green (#10b981) - Positive actions, confirmations, available items
- **Error**: Red (#ef4444) - Errors, destructive actions, unavailable items
- **Warning**: Amber (#f59e0b) - Warnings, cautions, pending states
- **Info**: Blue (#3b82f6) - Informational messages, hints

#### Neutral Colors
- **Text**: #000000 (dark), #666666 (medium), #999999 (light)
- **Backgrounds**: #ffffff (white), #f5f5f5 (light gray), #e8e8e8 (medium gray)
- **Borders**: #d0d0d0 (standard), #e0e0e0 (subtle)

## Shadow System

Elevation hierarchy using shadows to create visual depth:

### Shadow Sizes
- **sm**: Subtle elevation for small interactive elements

## Accessibility (a11y)

All components meet WCAG 2.1 Level AA standards:

- ✓ Keyboard navigation (Tab, Arrow Keys, Enter, Escape)
- ✓ Screen reader support (proper ARIA labels and roles)
- ✓ Color contrast (4.5:1 for normal text, 3:1 for large text)
- ✓ Focus indicators (visible yellow outline)
- ✓ Reduced motion support (respects prefers-reduced-motion)
- ✓ Touch target sizes (minimum 24x24px for interactive elements)

## Animations

### Motion Principles
- **Duration**: Animations last 200-300ms for responsive feel
- **Easing**: cubic-bezier curves for natural motion
- **GPU Acceleration**: Uses transform and opacity for smooth 60fps
- **Respect Preferences**: Disabled via prefers-reduced-motion

### Common Animations
- **Page Transitions**: 300ms fade and slide
- **Card Hover**: 200ms scale and shadow elevation
- **Modal Entry**: 300ms scale and opacity
- **Loading States**: Spinner rotation and fade

## Hebrew & RTL Support

The design system is built from the ground up for Hebrew and right-to-left languages:

- All text inputs use `dir="rtl"`
- Layouts use logical properties (start/end instead of left/right)
- Components account for Hebrew text weight and spacing
- Testing includes bidirectional text and line breaking
