# מפרט UI לקוח

‏mobile-first. נמדד מול
`src/app/(account)/`
,
`src/components/account/AccountNav.tsx`
, ומסכי שובר ציבוריים.

## ניווט חשבון

| מסך | נתיב | מצב ריק (קופי חי) |
|---|---|---|
| בית חשבון | ‏`/account` | סיכום הזמנות/שוברים |
| פרטים | ‏`/account/details` | - |
| הזמנות | ‏`/account/orders`, ‏`/[id]` | עוד לא ביצעת הזמנות. |
| חשבונית | ‏`/account/orders/[id]/invoice` | הפניה ל-URL ספק/‏R2, לא הדפסה מקומית |
| קופונים / שוברים | ‏`/account/coupons` | עדיין לא רכשת קופונים. |
| ארנק | ‏`/account/wallet` | עדיין אין תנועות בארנק. |
| הפניות | ‏`/account/referrals` | עדיין לא הצטרף אף אחד דרך הקוד שלכם. |
| כתובות | ‏`/account/addresses` | עדיין לא הוספת כתובת. |
| כרטיסים שמורים | ‏`/account/tokens` | ראה ‏TokenManager |
| מנויים | ‏`/account/subscriptions` | אין לך מנויים פעילים. |
| אבטחה | ‏`/account/security` | ‏2FA / מפתחות |
| משאלות | ‏`/account/wishlist` | (‏W4 מעמיק) |

הפניות קבועות: ‏`/account/vouchers` ו-‏`/account/my-vouchers` → ‏`/account/coupons`.

## מחוץ ל-`/account`

| מסך | נתיב | תפקיד |
|---|---|---|
| שובר בודד | ‏`/coupon/[id]` | הצגת ‏QR + יתרה לתשלום בעסק |
| מימוש בטוקן | ‏`/redeem/[token]` | מסלול מימוש ייעודי |
| עגלה | ‏`/cart` | אורח + מחובר |
| קופה | ‏`/checkout` | מתג ‏`CHECKOUT_ENABLED` |

## שוברים

- כותרת משנה חיה: «הצגת הקוד או ה-QR בבית העסק. היתרה משולמת שם בזמן הסריקה.»
- מחיר לתצוגה = מחיר הקופון באתר, לא ‏`price_ils` של בית העסק.
- אחרי מימוש / החזר: סטטוס ברור, בלי אפשרות סריקה שנייה מצד הלקוח.

## ארנק

מקור תשלום בלבד. לא משנה עמלה ולא קאשבק שצולם. יתרה והיסטוריה באגורות
→ תצוגת ש״ח דרך פורמט הכסף.

## הפניות

קוד אישי קבוע. בונוס = שורת ספר, לא הבטחת אחוז בקופי שיווקי חופשי.
מסך ריק לפני שיש מופנים.
