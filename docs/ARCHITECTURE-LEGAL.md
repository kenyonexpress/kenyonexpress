| סטטוס | משמעות |
|---|---|
| **טיוטת תוכן** | כל נוסח עברי בסעיפים 4-8 הוא **טיוטה הנדסית / עסקית**, לא ייעוץ משפטי. |

|---|---|
| `{{COMPANY_NAME_HE}}` | שם החברה בעברית |

## 0. מודל העסק (רקע לנוסחים)

KenyonExpress היא **פלטפורמת תיווך** (marketplace):

| סוג | מה הלקוח משלם באתר | מה קורה אצל הספק |
|---|---|---|
| קופון | מחיר קופון מלא באתר (`coupon_price`) | יתרת פנים (`face - coupon_price`) במזומן/אשראי אצל בית העסק בעת סריקת QR. **אין נאמנות (Escrow)** על כסף הקופון ששולם באתר. |
| פיזי | מחיר לאחר הנחה באתר | הספק מספק/שולח; עמלה לפי `platform_percent` שצולם בהזמנה |

`[לבדיקת עו"ד]` ניסוח "שלוחה לגבייה" מול "מוכר" בפיזי: ליישר עם `ARCHITECTURE-LEGAL-COMPLIANCE.md` §1.6 לפני פרסום.

## 1. Routes (מחייבים)

| Route | כותרת H1 | Footer | `robots` | `wording_version` key |
|---|---|---|---|---|
| `/terms` וגם `/terms-and-conditions` (redirect) | תקנון אתר | כן | index,follow | `TERMS_VERSION` |
| `/privacy` | מדיניות פרטיות | כן | index,follow | `PRIVACY_VERSION` |
| `/cancellation` וגם `/cancel-policy` | מדיניות ביטולים והחזרות | כן | index,follow | `CANCEL_VERSION` |
| `/cancel` | ביטול עסקה (טופס) | כן ("ביטול עסקה") | noindex | n/a (כלי) |
| `/accessibility` | הצהרת נגישות | כן | index,follow | `A11Y_VERSION` |
| `/cookies` | מדיניות עוגיות | כן + באנר | index,follow | `COOKIES_VERSION` |

Redirects:

## 3. עקרונות נוסח משותפים

1. עברית משפטית ברורה, בלי אנגלית למשתמש הקצה (חוץ משמות מותג / Cardcom).
2. מחירים באתר **כוללים מע"מ** אלא אם נאמר אחרת באישור עו"ד.
3. אין להבטיח "החזר מיידי" אם ה-SLA הוא עד 14 יום.
4. קופון שמומש (נסרק) ≠ ביטול רגיל; מנותב לסכסוך מול ספק / מדיניות נפרדת.
5. כל שינוי מהותי = `wording_version` חדש + באנר "עודכן בתאריך…" + שמירת אישורי עבר.

## 9. Checkout + ראיות הסכמה

| אירוע | נשמר |
|---|---|
| אישור תקנון בקופה | `orders.accepted_terms_at`, `orders.terms_version` |
| באנר אנליטיקה | cookie + אופציונלי `consent_events` |
| דיוור 30א | `consent_events` (מערכת התראות) |
| בקשת ביטול | `cancellation_requests` (ראו LEGAL-COMPLIANCE) |

```ts
// src/lib/legal/versions.ts
import { LEGAL } from '@/content/legal/meta'

export function currentTermsVersion(): string {
  return LEGAL.termsVersion
}

export function assertCounselApprovedForProduction() {
  if (process.env.NODE_ENV === 'production' && !LEGAL.counselApproved) {
    console.error('LEGAL_COUNSEL_NOT_APPROVED: publish blocked by policy')
    // Optional: throw in CI gate, not necessarily at runtime for soft launch staging
  }
}
```

שער CI מומלץ:

```yaml
# fail if counselApproved is false on main release tag
- run: pnpm exec tsx scripts/legal/assert-counsel.ts
```

## 10. רשימת סימון לבדיקת עו״ד (צ׳קליסט חתימה)

- [ ] פרטי עוסק מלאים (שם, ח.פ, כתובת, טלפון, דוא״ל)
- [ ] תקנון: מודל תיווך / מוכר בפיזי / הגבלת אחריות / סמכות שיפוט
