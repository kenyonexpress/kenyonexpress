## 1. מקרא סטטוס

| סטטוס | משמעות |
|---|---|
| `verified` | ספק קיים בשם המתוכנן + מחיר קופון/הנחה הגיוניים + אין דגל חשוד שחוסם publish |
| `missing-supplier` | שם הספק המתוכנן לא קיים ב-`suppliers` |
| `suspicious-data` | ספק/מוצר קיימים אבל כסף, קטגוריה, מלאי או שיוך לא הגיוניים |

כללי הנחה הגיונית לקופון (No Escrow):

- `0 < coupon_price_ils < price_ils` (face)
- הנחה מוצגת בערך 25% עד 60% (מחוץ לטווח = חשוד)
- `platform_percent` פר מוצר, לא null (בקופון לביקורת; payout קופון = 0)
- מלאי קופון / מכסה > 0 לפני publish

## 5. חמש פעולות אדמין מדויקות להשקה

1. **`/admin/suppliers`:** צור (או ייבא) את 10 הספקים המתוכננים בשמות המדויקים מהטבלה למעלה, עם לוגו + טלפון + כתובת + `status=active`. בלי זה אף דיל לא יוצא מ-`missing-supplier`.

2. **`/admin/products` (קופון):** לכל דיל #1 עד #10 צור מוצר `type=coupon` עם `price_ils` / `coupon_price_ils` / `platform_percent` / `supplier_split_percent` מהתוכנית, תמונה ראשית אמיתית (לא picsum), ו-`stock_quantity` או מכסת קופון ≥ 20.

3. **נקה דמו חוסם:** תקן או הסתר `ארוחת בוקר בופה` תחת בוטיק אופנה, `ארוחה טבעונית` תחת ספא רוגע, וכל `demo-coupon-*` עם מחיר `*.5` שלא מיועד להשקה (מונע בלבול בקרוסלת הבית).

4. **שער כסף:** ודא שבטופס האדמין אין publish בלי `platform_percent`, וש-`coupon_price_ils < price_ils`. הרץ קניית טסט אחת על דיל #1 אחרי `CHECKOUT_ENABLED=true` + Cardcom (ראה `LAUNCH-CHECKLIST.md` B1/B11).

5. **סימון השקה בבית:** סמן רק דילים שעברו ל-`verified` אחרי שלבים 1 עד 4 לקרוסלת "מבצעי השקה" / featured; אל תעלה את עשרת ה-seed עד שסטטוס בטבלת §2 מתעדכן.
