
### 2.1 שלב 3 קודם לשלב 5, תמיד

**מיתון אינו תיקון.** ‏דגל שמכבה קופה שבורה עדיף על שעתיים דיבוג בזמן
שלקוחות מחויבים כפול.

**כלים למיתון שכבר קיימים:**

| כלי | מה הוא עוצר |
|------|--------------|
| ‏`CHECKOUT_ENABLED=false` | סוגר קופה |
| ‏`ALERTS_ENABLED` | ‏**אזהרה: משתיק את כל הערוץ.** לא בזמן תקלה. |
| ‏`updateTag(CATALOGUE_TAG)` | מרענן קטלוג תקוע |
| ‏rollback ב-Vercel | חוזר לפריסה קודמת |
| ‏`is_active = false` על קטגוריה | מסתיר תוכן שבור |

**‏rollback הוא כמעט תמיד המיתון הנכון**, אם התקלה החלה אחרי פריסה.
**הבדיקה הראשונה בכל תקלה: מתי הייתה הפריסה האחרונה.**

## 3. טריאז' לפי תסמין

| תסמין | בדיקה ראשונה | סביר |
|--------|---------------|-------|
| האתר לא נטען | ‏`/api/health`, סטטוס Vercel | פריסה או ‏Vercel |
| הקטלוג ריק | ‏`database` בבריאות | ‏**קריאה כושלת שנשמרה ב-cache** |
| התשלום נכשל | ‏`cardcom` בבריאות, ‏`payment_webhook_events` | ‏Cardcom או תצורה |
| שוברים לא נשלחים | ‏`email`, ‏`notification_outbox` | ‏Resend או ה-outbox |
| שובר לא נסרק | ‏`vouchers.state` | ‏**‏SEV1** |
| חיוב כפול | ‏`payments` לפי סכום וזמן | ‏**‏SEV1** |
| החיפוש ריק | ‏`search`, ‏DLQ | ‏Meilisearch |
| האתר איטי | ‏`load/browse.js` | ‏§6 |
| ‏429 לכולם | ‏`rate_limit.open` בלוגים | ‏§3.1 |

### 3.1 ה-cache הוא החשוד הראשון בקטלוג ריק

**קריאת קטלוג כושלת שנשמרה ב-`use cache` היא חנות ריקה ללא שורה בשום לוג.**
זה כבר קרה, וזה מה שהוליד את החוזה ב-`catalogue-cache.ts`.

**מוצר שנשמר בלי `updateTag(CATALOGUE_TAG)` נשאר בלתי נראה עד שעה, האדמין
רואה אותו בפאנל, ושום דבר לא מדווח על בעיה.** ‏זה נראה כמו בעיית DB והוא
לא. **זה תמיד יהיה החשד הראשון בכל תקלת "המוצר לא מופיע".**

### 3.2 שני הגבולות של ה-`x-forwarded-for`

תקלת ‏429 המונית: אם האפליקציה מוגשת ממשהו שאינו כותב מחדש את הכותרת,
כל מפתחות ה-IP קורסים לדלי אחד. ‏`RATE-LIMITING-STRATEGY.md` §4.

### 5.1 הסעיף שאסור לדלג עליו

**"מה תפס ומה לא".**

יש כאן ‏3,696 טסטים, ‏type-check, ‏lint, ‏E2E ושער פיקסלים. ‏**תקלה שהגיעה
לפרודקשן עברה את כולם**, ולכן השאלה אינה "מה נשבר" אלא **"למה שום שער לא
ראה".**

**כל ‏postmortem של ‏SEV1 חייב לייצר לפחות פעולה אחת מסוג "שער".** תיקון
בלי שער מזמין את אותה תקלה שוב.

**זה כבר הוכח כאן:** ‏`style={{width:'auto'}}` שהשתיק אזהרת dev שבר ‏31
מתוך 31 התמונות בדף הבית, ו-**השמירה שהייתה קיימת פספסה אותו כי היא בדקה
"לא התמוטט" על הכרטיס הראשון בלבד.**
