כתובת קטגוריה באתר החדש:
/category/{slug}

כתובת אזור:
/city/{slug}

כותרת SEO ≤60 תווים. מטא ≤155 תווים. הספירה כוללת רווחים. המותג בכותרת הוא "קניון Express" פעם אחת. H1 נשאר שם התפריט החי, גם כשהכותרת מקוצרת.

```

```

## 2. הצעת תתי-קטגוריות

תתי-הקטגוריות הן query או child slug בעתיד, לא חובה בשיגור. בשיגור: קטגוריה אחת + סינון עיר. בלי תת-קטגוריה ריקה באינדקס.

כתובת עתידית מוצעת:
/category/{parent}/{child}

או
/category/{parent}?sub={child}

## 3. טקסונומיית ערים: 17 אזורים מבורר האזור החי

האתר החי הציג בורר "בחר אזור" עם 17 ערכים (המפרט כתב 16 וספר 17). בפרויקט הבורר הוסר מהכותרת. הנתיב הציבורי המוצע:

```
/city/{slug}
```

זה דף נחיתה: קופונים באזור, H1 שם האזור, קנוניקל בלי `?page=`. סינון קטגוריה קיימת נשאר
`/category/{slug}?city={slug}`

## 7. כללים אחרי הדבקה ב-CMS

1. H1 = שם התפריט החי.
2. כותרת ומטא בשדות
   `seo_title`
   /
   `seo_description`
   או
   `categories.description_he`,
   לא דריסת H1.
3. קטגוריה עם אפס מוצרים פעילים: `noindex` או 404.
4. `?city=` ו-`?page=` לא נכנסים לקנוניקל.
5. אחרי cutover: 301 מ-
   `/product-category/`
   אל
   `/category/`.
