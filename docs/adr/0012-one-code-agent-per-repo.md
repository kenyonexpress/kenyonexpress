# 0012 — סוכן קוד אחד על הריפו בכל רגע

**סטטוס:** כלל עצירה קשה.

סוכן שני על אותו checkout הוא אחת מארבע העצירות הקשות. הראיות שמאחורי
הכלל מתועדות כזכרונות: ‏autosave שגונב WIP לקומיטים שלו, ‏builds מקבילים
שהורגים זה את זה ב-OOM, ‏worktrees עם symlink ל-node_modules שמרוקן את
הראשי, ו-commit-עם-paths שסוחב עריכות של אחרים. כשחייבים מקביליות —
‏worktree נפרד + שערים שאינם build.
