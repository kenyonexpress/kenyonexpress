### How it stays fresh

The reads are `'use cache'` + `cacheLife('hours')` + `cacheTag(CATALOGUE_TAG)`,
so an admin save that calls `updateTag` refreshes them immediately, and anything
else refreshes within an hour. The response sets `s-maxage=3600,
stale-while-revalidate=86400`. Every read goes through `orFail`, so a failed
Supabase read can't cache an empty sitemap.
