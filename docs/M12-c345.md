## Verdict
- SAFE: `Allow: /`, no `Disallow: /` (count above = 0). Private/credential paths (redeem, coupon, voucher, gift, account, supplier, admin, checkout, cart, auth, api, debug, reset/forgot-password) are disallowed. 200, text/plain.
- FINDING (non-blocking, config not code): production `NEXT_PUBLIC_APP_URL` is the apex `https://kenyonexpress.co.il`, which 308-redirects to `www`. So `Sitemap:`, `Host:`, sitemap `<loc>`s and the homepage canonical all use the apex host while the served host is www. Crawlers follow the redirect, so nothing is blocked, but canonical/sitemap host should match www. Fix = set NEXT_PUBLIC_APP_URL=https://www.kenyonexpress.co.il in Vercel production and redeploy (code default in src/lib/site-url.ts is already www). Not changed here: it is a production env change that affects canonicals site-wide, beyond this verification item.
