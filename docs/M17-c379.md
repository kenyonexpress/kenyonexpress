`https://www.kenyonexpress.co.il`. Read-only: no code changed. `src/`,
`public/`, `messages/` and `supabase/` are unchanged since the M17-c378 base

## Result

**No Hebrew text renders left-to-right on `/` or on the five sampled product
pages at 380, 768 or 1440. Unchanged since M17-c378.**

Two full passes of 18 loads (6 pages x 3 widths), both entirely on HEAD's
deployment, both with 0 leaks on every load:

- `<html dir="rtl" lang="he">`, and `body` computes `direction: rtl`, 36 of 36.
- 0 visible elements whose own text contains Hebrew compute `direction: ltr`
  (88 to 197 Hebrew text elements per load).
- 0 Hebrew text elements compute `text-align: left`, or `start` under LTR.
- 0 elements get `direction: ltr` from CSS, other than the 20 numeric discount
  badges on `/`.
- Horizontal overflow is 0 px on every load.
- 36 of 36 loads: HTTP 200 with the real `h1`. 0 failed navigation attempts,
  0 unmeasured, 0 error screens.

**Pass 2 is the measurement of record.** Pass 1's last load
(`demo-store-voucher` at 1440) lost the probing Mac's network after its RTL
line had been recorded: 54 errors, all `net::ERR_NETWORK_CHANGED` then
`net::ERR_NAME_NOT_RESOLVED` on static chunks, fonts and `/_next/image`
requests, no HTTP status at all. The RTL counts on that load are the same as
in pass 2 except `walked` (392 against 394, two lazy elements not mounted). The
other 17 loads of pass 1 are `errors=0` and line-for-line identical to pass 2
(`diff run.txt run2.txt` differs only on that one load and its error lines).
Pass 2, 18 of 18 `errors=0`, no network drop.

## What computes LTR, and why each is not a text leak

| What | Where | Count | Text inside | Verdict |
|---|---|---|---|---|
| `span.discount_per`, `direction: ltr` from CSS | `/` only | 20 per load | `-NN%`, no Hebrew (the probe checks the text of each one) | Deliberate. LTR keeps the minus sign before the number. |
| `a[dir="ltr"]` supplier phone link | all 5 product pages | 1 each | `052-4635550` (3 pages), `972524635550` (2) | Deliberate. A phone number is Latin digits. |
| `input[type=email][dir="ltr"]`, footer newsletter | every page, visible at 1440 | 1 | Hebrew placeholder `הזן כתובת אימייל`, `text-align: start` | Known exception, BACKLOG #25. Not changed: `src/components/layout` is frozen. |

The set of `dir="ltr"` elements on each page is the same at all three widths
and in both passes.

## Probe

`/tmp/m17-c379/work/probe.cjs` (Playwright Chromium, locale he-IL, not
committed). It is M17-c378's probe with one change: the output directory in
the error-screen screenshot path (`sed` over the `/tmp/m17-c378` prefix). The
checks and the navigation retry are untouched.

It walks every element in `body` outside `svg` (349 to 967 per load).

(08:04:10 to 08:08:25), pass 2 took 4.7 min (08:08:49 to 08:13:32, sharing
the uplink with the control run).
