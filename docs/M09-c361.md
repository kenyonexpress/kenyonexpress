## What knip still reports, and why it stays

`pnpm dlx knip@5 --no-config-hints --reporter compact`, after the removals:

```
Unused files (208)
Unused dependencies (1)
package.json: @radix-ui/react-dropdown-menu, @radix-ui/react-select, postgres, react-hook-form
Unused devDependencies (1)
package.json: lighthouse
Unused exports (146)
Unused exported types (360)
```

- `postgres`: imported by `scripts/_voucher-race.mjs`, `scripts/db-doc.mjs` and `scripts/dr/*`. Knip has no entry for `scripts/`, so it lists those scripts as unused files and their imports as unused deps.
- `@radix-ui/react-select`, `@radix-ui/react-dropdown-menu`, `react-hook-form`: their only importers are `src/components/ui/{select,dropdown-menu,form}.tsx`. Those files are under `src/components/`, which the 04.11 design freeze says must never be edited. Deleting them would put existing files in the freeze diff, so these three deps stay until the freeze is lifted.
- `lighthouse`: run as `node_modules/.bin/lighthouse`, for example in M08-c361.
- Unused files under `src/components/**` (the store/ re-export shims and the rest, listed in `scripts/dead-component-known-issues.json`): frozen, not touched.
- 146 unused exports: sampled, and the list is not reliable enough to act on in bulk. `multiplyAgorot` is re-exported through `src/lib/commerce/money.ts` and used in settlement. `formatCurrency` in `src/lib/i18n/format.ts` is a documented alias of `shekels`. The `__reset*Warning` functions are test hooks. Several more are payment and ledger APIs (`postJournal`, `createTokenizedCharge`). Removing `export` keywords across the money path for a lint count adds risk and does nothing for users. The only export removed is the one above, which was dead with certainty.
