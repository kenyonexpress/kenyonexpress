# M15-c361: no console errors on / and a product sample

Measured 05.11.2026, ~04:40 +07, against a fresh `pnpm build` of HEAD
`18624c96a` served by `PORT=3311 pnpm start` (listener PID 54992, stopped by
PID afterwards). I could not measure production, because it answers 503 on every
route while it is in maintenance mode:

```

$ curl -s -o /dev/null -w "%{http_code}" https://www.kenyonexpress.co.il/product/barbecue

```

## Result

**The app itself logs no console errors on /, /product/barbecue or
/product/bar-drink at 380 or 1440.** There were 0 `pageerror`s and 0 hydration
warnings. All 50 captured entries fall into three classes, and each one exists
only when the site runs under local `next start`:

| Class | Why it happens only locally |
|---|---|
| `/_vercel/insights/script.js` 404 + strict-MIME refusal | The Vercel platform serves this path for `@vercel/analytics`. `next start` has no such route. |
| `/_vercel/speed-insights/script.js` 404 + strict-MIME refusal | Same cause, for `@vercel/speed-insights`. |
| `/_next/image?...` 404 (one, on / at 1440) | `images.loader: 'custom'` turns off the local optimizer route. Vercel serves `/_next/image` itself (see memory local-next-image-endpoint-404s-with-custom-loader). |

I made no code change. Nothing failed that a fix in the repo could make green.
