## שלוש פעולות ידניות שנשארו רק לך

הסוכן לא יכול לבצע אותן. בלי שלושתן אין כסף אמיתי על הדומיין החי. פירוט ושערים:
`docs/QUESTIONS-FOR-OFIR.md`
(Q1, Q3, Q9) ו-
`docs/LAUNCH-DAY-PLAN.md`.

### 1. מפתחות Cardcom לייצור

Chrome: דשבורד Cardcom + Vercel Project → Settings → Environment Variables, סביבת Production בלבד.

להזין (לא לשלוח בצ'אט, לא ל-git):

```
CARDCOM_TERMINAL_NUMBER
CARDCOM_API_NAME
CARDCOM_API_PASSWORD
CARDCOM_WEBHOOK_SECRET
```

הלקוח בקוד הוא
`/Interface/*.aspx`
(לא v11). אין חתימת webhook: הסוד הוא `?s=` + אימות GetLpResult.

אחרי ההזנה, לפני דגל הקופה: רכישת קופון מינימלית בכרטיס שלך, refund מתועד. רק אז
`CHECKOUT_ENABLED=true`
ב-Production (המחרוזת המדויקת `true`). Preview נשאר sandbox. לא באותו יום עם DNS cutover.

### 2. פרטי חברה

הערכים שמחליפים את
`COMPANY_LEGAL_TBD`
(D9) ומופיעים בתקנון, בחשבונית וב-14ג:

| שדה | ערך |
|---|---|
| שם משפטי עברית | |
| ח.פ / ע.מ | |
| כתובת | |
| מייל משפטי | |
| טלפון תמיכה (גם D8) | |

אחרי שיש ערכים: להדביק את פרומפט D9 (ו-D8 אם יש טלפון). חתימת עו"ד לתקנון נשארת אצלך. בלי ח.פ אמיתי אין חשבונית.

### 3. DNS cutover

היום
`https://kenyonexpress.co.il`
מגיש WordPress מאחורי Cloudflare (HTTP 200). זה מעבר מתוזמן, לא DNS חסר.

סדר קשיח: מסוף Cardcom ירוק על Preview/staging עם אותו קוד → כיסוי 301 → TTL 300 → cutover ב-Cloudflare ל-Vercel Production (לא ל-Preview) → WP חי שבועיים ל-rollback.

אין cutover בלי סעיף 1. אין cutover באותו יום עם החלפת מסוף. אין
`CHECKOUT_ENABLED=true`
על דומיין שעדיין מגיש חנות שלא גובה, ואין לכבות WP ביום שבו ה-Next עדיין עם קופה כבויה בלי הודעה ללקוחות.
