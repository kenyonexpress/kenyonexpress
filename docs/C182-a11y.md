## Root cause and fix (`src/app/(store)/developers/page.tsx`)

1. **Contrast 3.46:1.** The page was written in shadcn vocabulary, where
   `bg-muted` is a pale surface. In this project, `--color-muted` is
   `#6f6f6f`, the *muted text* token (`src/styles/tokens.css:94`). Nine
   `bg-muted` panels painted dark gray behind `#1a1a1a` text. They now use
   `bg-surface-hover` (`#f5f5f5`, an existing surface token), about 16:1.
2. **Code scrollers unreachable from the keyboard (2.1.1).** Five
   `overflow-x-auto` divs around `<pre>`. The overflow moved onto the `<pre>`,
   which got `tabIndex={0}` and `aria-label="Code sample"`, with a
   `biome-ignore noNoninteractiveTabindex` and its reason. That is the same
   pattern `LegalArticle.tsx` uses for the legal tables.
