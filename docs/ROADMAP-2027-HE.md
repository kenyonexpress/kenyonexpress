# מפת דרכים 2027 (אחרי v5.1.0)

Status: DRAFT · docs only  
נקודת התחלה: תג `v5.1.0` ירוק בייצור (PWA push תפעולי + wallet passes כשהתעודות קיימות, או כפתור מוסתר עם API 404).  
אם `v5.1.0` מתאחר, כל הרבעונים זזים יחד. לא מדלגים על תלויות כסף.

לא מחליף:

- `docs/growth/V2-ROADMAP-HE.md` (פירוט PWA, passes, AI, bundles, flash, loyalty, i18n לשישה חודשים אחרי v5.0.0)
- `docs/ROADMAP-POST-LAUNCH.md` (Cardcom ייצור, Resend, R2, cron)
- `docs/growth/POST-LAUNCH-BACKLOG.md`

2027 מתחיל **רק** אחרי: עסקת אמת אחת, מייל שובר חי, סריקה יציבה, ומתזמן ל-10 ה-cron (או תחליף שנמדד). בלי זה הרבעון הראשון הוא תפעול, לא פיצ'ר.

מאמץ: S / M / L כמו ב-v2. אין `db push`. כסף באגורות. RTL עברי מקור UI.

## תלויות שחוסמות את כל השנה אם נשברות

```
Cardcom prod + webhook חתום
    + Resend + דומיין מייל
    + cron חיצוני
        -> כל מייל שובר ו-KPI כסף

v5.1.0 push/passes
        -> Q1 מדידה ושיווק תפעולי ב-push בלי 30א על אותם kinds

מיגרציה מנויים מאושרת
        -> Q3 מנויים; אחרת דילוג מודע

החלטת בעלים על פיזי
        -> Q3/Q4 פיזי ציבורי; אחרת נשאר טיוטה
```

שני סוכני קוד על אותו repo: עצירה, לא פריט בלוח.
