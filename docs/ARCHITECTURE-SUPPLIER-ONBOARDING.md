## 0. עקרונות מחייבים

1. ספק לא עולה לאוויר בלי אימייל תפעולי + אישור אדמין/בעלים.
2. לפני publish: לכל מוצר פיזי חובה `platform_percent` (דינמי, בלי ברירת מחדל). לכל קופון חובה `coupon_price_ils` מוחלט.
3. הסבר כספי לספק: מקדמת קופון שנגבית באתר **נשארת בפלטפורמה**; יתרה נגבית במזומן/בקופה בעסק בסריקה. **אין Escrow** ואין שחרור מקדמה לספק.
4. פיזי: הלקוח משלם 100% באתר; הפלטפורמה שומרת את אחוז ה-snapshot; היתרה ל-payout לפי מדיניות T+3.
5. אין עמלת 5%/10% קבועה במערכת או בחוזה התפעולי כברירת מחדל.

## 1. תהליך צירוף (end-to-end)

```
Lead / פנייה
  → איסוף מסמכים (§2)
  → בדיקת אדמין (KYC קל)
  → יצירת public.suppliers (status=pending)
  → הזמנת משתמש ל-supplier_members (Google)
  → הדרכת כסף + סורק QR (§5)
  → הגדרת platform_percent / coupon_price על מוצרים (§4)
  → מוצרים ב-draft → אישור אדמין → published
  → go-live ספק (status=active)
  → מעקב שבוע ראשון (סריקות / משלוחים)
```

| שלב | בעלים | יציאה |
|---|---|---|
| Lead | מכירות/בעלים | טופס מלא |
| KYC | אדמין | מסמכים תקינים |
| Account | אדמין | שורת supplier + member |
| Catalog | ספק + אדמין | ≥1 מוצר מאושר עם כסף תקין |
| Live | אדמין | status active + ספק בפורטל |

השעיה: אדמין יכול `suspended` → unpublish מוצרים + חסימת סורק.

## 4. הגדרת `platform_percent` ומחירי קופון

### 4.1 פיזי

| כלל | פירוט |
|---|---|
| שדה | `products.platform_percent` |
| חובה | NOT NULL לפני publish (מיגרציה 050+) |
| ברירת מחדל | **אין**. האדמין/הספק (באישור) מזינים ערך פר-מוצר |
| טווח | לפי validation אדמין (למשל 0 < x ≤ 100); לא מקודד 5 |
| צילום | ב-`order_items` בזמן קנייה; שינוי אחר כך לא משכתב הזמנות ישנות |
| חשיפה ללקוח | **לא** מציגים את האחוז ב-PDP (הלקוח משלם מחיר מלא) |

### 4.2 קופון

| כלל | פירוט |
|---|---|
| שדה מחיר באתר | `products.coupon_price_ils` מוחלט |
| גבייה | מלוא הסכום ב-Cardcom באתר |
| `platform_percent` על קופון | לא משמש לפיצול מקדמה לספק (מודל סופי: 100% לפלטפורמה). יכול להישאר לדיווח פנימי בלבד או 100 ב-snapshot |
| יתרה בעסק | face − coupon_price; לא עוברת בפלטפורמה |
| תוקף | `coupon_expiry_days` / `offer_valid_until` חובה לפני publish |

### 4.3 שערי publish (אדמין)

| בדיקה | חוסם |
|---|---|
| `supplier_id` משויך | כן |
| פיזי: `platform_percent` מולא | כן |
| קופון: `coupon_price_ils > 0` ו-≤ face | כן |
| תמונה ראשית | כן (מדיניות תוכן) |
| הוראות מימוש בעברית (קופון) | כן |

## 5. הדרכת ספק (יום go-live)

צ'קליסט שיחה / PDF קצר:

1. איך נכנסים ל-`/supplier` (Google).
2. סריקת QR: חד-פעמי; מה הלקוח משלם בעסק.
3. **אין** ציפייה לקבל את מקדמת האתר מהפלטפורמה.
4. הזמנה פיזית: התראה + עדכון shipped.
5. איפה רואים יתרת payout (פיזי בלבד).
6. מי לתמיכה ב-KE (לא לשנות מחירים בלי אדמין אם נדרש אישור).

נוסח אסור בהדרכה: "Escrow", "נאמן", "נשחרר 90% אחרי סריקה" (לגבי מקדמת אתר).
