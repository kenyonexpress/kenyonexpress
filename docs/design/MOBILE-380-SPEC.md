## מה לא למדוד כשער 380

1. גובה העמוד המלא (17825 מול 10358): קטלוג שונה, לא עיצוב כותרת.
2. תמונות בתוך `display:none`.
3. masthead דסקטופ ב-0×0: זה נכון, לא באג.
4. אזור ווידג'טי פוטר שחזר 0×0 בסלקטור: לבדוק ידנית שהפוטר נערם, לא להכשיל שער על סלקטור שבור.

`pnpm start`

```
LOCAL_BASE=http://localhost:3311 node scripts/compare.mjs --page=home --width=380
```
