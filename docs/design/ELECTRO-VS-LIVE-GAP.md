# פער Electro מול האתר החי

תאריך: 2026-09-02.
היקף: docs בלבד.

## מקורות

הקבצים
`electro.html`
ו-
`electro_madrasthemes_com-DESIGN.md`
לא נמצאים ב-worktree. הקובץ
`electro-full.html`
הוא דף Cloudflare challenge, לא התבנית. הפער נבנה ממדידות שכבר בריפו:

| מקור | מה נלקח ממנו |
|---|---|
| `DESIGN-MEASURED.md` | טוקנים שנמדדו מ-electro.madrasthemes.com/home-v7 ומ-kenyonexpress.co.il |
| `src/lib/electro-hero-tokens.ts` | גריד הירו, USP, רצועת קטגוריות, טיפוגרפיה. הערות inline על 220 מול 241 |
| `KE_LIVE_SPEC.md` | DOM החי, פלטה, סטיות מכוונות |
| `MEASURED-LIVE.md` | getComputedStyle ב-1440×900 וב-375×812 |
| `HOMEPAGE_SPEC.md` | מבנה הבית בפרויקט |
| `AUTOPILOT-PROMPT.md` | כלל: Electro הוא השראה מבנית. היעד הפיקסלי הוא האתר החי |

עמודה **המלצה**:

- **adopt**: להעתיק מהדמו אל הפרויקט כי החי כבר עושה כך, או כי זה משפר בלי לשבור שער פיקסלים.
- **skip**: לא להביא. דמו אנגלית / LTR / אלקטרוניקה, או סטייה מכוונת ב-
  `KE_LIVE_SPEC.md`.
- **adapt**: לקחת את הרעיון, למדוד מחדש מול החי, לא להעתיק מספר מהדמו.

האתר החי רץ על תבנית
`electro`
עם child
`electro-child`,
RTL. הדמו הוא חנות LTR באנגלית. אי אפשר להעתיק פיקסל לדמו ולעבור את שער
`compare.mjs`
מול
`kenyonexpress.co.il`.

## כלל הכרעה

1. שער
   `compare.mjs`
   רץ מול האתר החי, לא מול הדמו. כל "adopt" מדמו שסותר מדידת חי נכשל בשער.
2. מספר שנמדד בדמו ואחר כך תוקן ב-
   `electro-hero-tokens.ts`
   (220→241, 200→201) נחשב **adapt**, לא adopt של הדמו.
3. רכיב שקיים רק בדמו (wishlist, reviews tab, mega עם תמונות, פילטר סיידבר) הוא **skip** אלא אם נפתח goal נפרד אחרי ההשקה.
4. עותק עברית תמיד מהחי. עותק אנגלית בדמו לא נכנס ל-UI.
