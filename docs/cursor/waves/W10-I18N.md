# W10 i18n

Code-agent spec. `next-intl` declares `he` + `en`. UI copy is Hebrew literals. Enabling `/en` ships a half-translated site. Pixel gate vs Electro **Hebrew** refs will fail if EN is forced through the same 11% compare.

---

## What it builds (honest minimum, post-launch)

1. Decision once: prefix `/en` vs subdomain. Prefix is less DNS.
2. `hreflang` + `x-default` = Hebrew.
3. Legal EN/AR only with counsel. No machine-translated 14-day copy.
4. Money/date/phone stay `he-IL` format until a complete formatter. **Never** switch agorot to locale decimal strings.
5. Logical CSS (`ps`/`pe`). Audit physical `left`/`right`.

**Do not build before W49** unless product insists. Default: keep `/en` routed off.

---

## Tables

Content is `*_he` columns. A `*_en` set is a migration (human). Search: Meili locale filter or a second index. Hebrew synonyms do not apply to English.

---

## RLS

Unchanged. Do not leak draft translations.

## Money invariants

`formatIls` / `he-IL` currency. Invoice legally Hebrew even if UI is EN (counsel). Coupon copy must not become "10% off face" in English.
