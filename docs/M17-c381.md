# M17-c381: RTL on / and a five-page product sample, measured on production

Measured 07.11.2026, 18:23 to 18:36 +07 (11:23 to 11:36 UTC), against
`https://www.kenyonexpress.co.il`. Read-only: no code changed. `src/`,

## Result

**No Hebrew text renders left-to-right on `/` or on the five sampled product
pages at 380, 768 or 1440. Unchanged since M17-c380.**

Two full passes of 18 loads (6 pages x 3 widths), both on HEAD's deployment,
both with 0 leaks on every load, and line-for-line identical in every RTL
count:

- `<html dir="rtl" lang="he">`, and `body` computes `direction: rtl`, 36 of 36.
- 0 visible elements whose own text contains Hebrew compute `direction: ltr`
  (91 to 197 Hebrew text elements per load).
- 0 Hebrew text elements compute `text-align: left`, or `start` under LTR.
- 0 elements get `direction: ltr` from CSS, other than the 20 numeric discount
  badges on `/`.
- Horizontal overflow is 0 px on every load.
- 36 of 36 loads: HTTP 200 with the real `h1`. 0 failed navigation attempts,
  0 unmeasured, 0 error screens.
- Pass 1: 18 of 18 loads `errors=0`. Pass 2: 17 of 18 `errors=0`; the one
  exception is `חבילות-עיסוי-זוגיות-בסוויטה-ספא-בוטיק` at 768: one
  `net::ERR_HTTP2_PING_FAILED` on a static chunk and two `net::ERR_ABORTED`
  client-side cancels on `/_next/image` (product photo and logo), no HTTP
  status on any of the three, recorded after the page had loaded with status
  200 and the real `h1`. The RTL counts on that load are identical to pass 1.
  All three URLs answer 200 afterwards (listing below). `diff` of the two
  pass listings differs only in those error lines. Same transport code as the
  pass 4 load in M15-c381.

## Probe

`/tmp/m17-c381/work/probe.cjs` (Playwright Chromium, locale he-IL, not
committed). It is M17-c380's probe with one change: the output directory in
the error-screen screenshot path (`sed` over the `/tmp/m17-c380` prefix,
`diff` shows that one line). The checks and the navigation retry are untouched.

Each page loads, waits 3 s, then scrolls 10 x 1200 px so lazy sections mount.
It walks every element in `body` outside `svg` (356 to 967 per load).
Requests to PostHog were aborted so the probe stays out of product analytics.

(11:24:19 to 11:28:14), pass 2 took 5.6 min (11:28:32 to 11:34:09).
