# מפרט תנועה ומשוב

אין ‏framer-motion בתלויות. התנועה הקיימת היא ‏CSS / Tailwind / Radix.
יעד הבלוק העתידי 85: אחידות בלי ‏layout shift.

## עקרונות

1. תנועה מסמנת היררכיה ונוכחות, לא רעש.
2. ‏`prefers-reduced-motion: reduce` מכובה אנימציות לא חיוניות בכל האתר
   (‏`globals.css`).
3. אפס ‏CLS מכוון בטעינת נתונים: שלד בגודל קבוע או שמירת מקום לתמונה.
4. משוב הצלחה/שגיאה מיידי על כל מוטציה שנוגעת בכסף או בשובר.

## מה קיים היום

| דפוס | איפה | התנהגות |
|---|---|---|
| הירו fade | ‏`HeroSlider.tsx` | ‏`transition-opacity duration-700`; ב-reduced-motion נשאר still |
| ספינר | ‏AddToCartButton, sonner | ‏`animate-spin` בזמן pending |
| Radix enter/exit | dialog, dropdown, select | ‏`animate-in` / fade / zoom |
| מעבר צבע | כפתורים, באנרים | ‏`transition-colors` |
| scale hover | חלק מכרטיסים | רק אם לא מזיז layout של שכנים |
| קטגוריה | ‏`category-page.css` | תנועה רק תחת ‏`prefers-reduced-motion: no-preference` |

## מצבי משוב חובה

| מצב | אות ויזואלי | גם ללא תנועה |
|---|---|---|
| טעינה | ספינר או שלד | טקסט «טוען…» / ‏aria-busy |
| הצלחה | toast / באנר ירוק | טקסט מפורש |
| שגיאה | באנר אדום / שגיאת שדה | טקסט מפורש + פוקוס לשדה |
| הוספה לסל | מונה כותרת + פתיחת מיני-עגלה | המונה מספיק אם המגירה חסומה |

## אסור

- אנימציה על מחיר או על סכום לתשלום שמסתירה את המספר הסופי.
- אוטופליי הירו לפני קלט משתמש (כבר נמדד כפוגע ‏LCP).
- מעבר שמוסיף גובה אחרי paint בלי שמירת מקום.
- הסתמכות על צבע בלבד לסטטוס שובר.
