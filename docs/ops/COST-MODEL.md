# מודל עלות חודשי (שירותים)

Status: DRAFT · docs only  
תאריך: 2026-09-03.  
מטבע תמחור ספקים: לרוב USD מחירון ציבורי. סליקה: ₪ לפי הסכם Cardcom (לא מצוטט כאן כהצעת מחיר).  
יחידת עומס: **הזמנות ששולמו** (`paid_at`) לחודש קלנדרי, לא sessions.  
ממוצע עבודה להזמנת קופון (הנחת תכנון, לא מדידה): ~2.5 מיילים תפעוליים, 1 webhook סליקה, 1–3 תמונות PDP ב-CDN, כמה עשרות בקשות HTML/API לגלישה לפני קנייה.

המספרים הם **רצועות תכנון**, לא חשבוניות. Capacity אמיתית לא נמדדה בפריוויו נפרד (`docs/CAPACITY.md`). לפני 100k: הרצת `load.yml` על preview.

אין Escrow. עלות הסולק היא על הסכום שנגבה באתר (מחיר קופון), לא על שווי הדיל.

| מיילים תפעוליים (~2.5×) | 2.5k | 25k | 250k |

AOV ₪40 הוא דוגמה בלבד (3900 אגורות במסמכי שותפים). להחליף ב-AOV חי מ-KPI.

## 2. טריגרי שדרוג (מתי לא לחכות לחשבונית אדומה)

| טריגר שנמדד | פעולה | לא לעשות |
|---|---|---|
| Vercel Hobby + צורך ב-10 crons | מתזמן חיצוני עכשיו; לשקול Pro | לסמוך על crons ב-`vercel.json` |
| Deployment 5xx / CPU throttling אחרי קמפיין | Pro + בדיקת functions | להגדיל concurrency בלי מדידה |
| Supabase CPU >~50% רצוף או timeouts ב-redeem | Compute add-on / ייעוץ אינדקסים | `db push`, כיבוי RLS |
| חיפוש ILIKE מזיז CPU עם קטלוג גדול | Meili + reindex | להשאיר ILIKE וגם 100k גולשים בחיפוש |
| Resend bounce > סף ספק | דומיין/DNS מייל, עצירת שיווק | שיגור חוזר לרשימה מתה |
| Twilio עלות > הכנסת פלטפורמה מאותו ערוץ | קיצוץ שיווק WA, השארת תפעול | win-back יומי |
| Sentry quota | סינון רעש, sample | לכבות ניטור באירוע |
| R2 class A חריג | מעלה מעלה כפילויות | picsum |
| Cardcom decline spike | פלייבוק תשלום, לא שדרוג תוכנית ענן | retry ChargeToken |
| 100k הזמנות בלי load test על preview | להריץ `load.yml` | להניח שמק מקומי = ייצור |

כיבוי קופה (`CHECKOUT_ENABLED`) הוא בלם כסף, לא חיסכון בעלות.

## 3. מה גדל ליניארית ומה לא

ליניארי בערך: סולק, מייל תפעולי, WhatsApp תפעולי, webhooks.

מדרגות: Vercel plan, Supabase compute, Meili cluster, תעודות Wallet.

כמעט קבוע: DNS, Apple Developer, ntfy.

חיסכון שגוי: לא למחוק `analytics_events` כדי "לחסוך DB" בלי קיצוץ IP sweep שכבר במדיניות (~90 יום).

## 4. תזרים מול עלות (קופון)

הכנסת פלטפורמה בקופון ≈ סכום `charged_on_site` (מחיר הקופון), לא שווי הדיל.  
אם AOV אתר ₪39 ו-1k הזמנות: ~₪39k לפני סולק, מע"מ, החזרים, קאשבק.  
סאס ב-1k (~₪100–350 לפי שער) אמור להישאר שולי.  
ב-100k הסאס עדיין שולי מול סולק והחזרים, **אם** אין Meili+Pro+Twilio שיווקי בלי רסן.

קאשבק ו-loyalty הם הנחה על הרווח, לא שורת AWS.
