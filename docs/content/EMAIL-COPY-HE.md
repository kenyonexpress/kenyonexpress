# עותק מיילים טרנזקציוניים (עברית, RTL)

תאריך: 2026-09-02.
היקף: docs בלבד. זה הנוסח שמותר לשלוח ללקוח. לא שיווק, לא הנחה שלא נרכשה.

## מסגרת מותג

| כלל | ערך |
|---|---|
| שפה | עברית. `dir="rtl"` על המעטפת ועל כל בלוק, לא רק על `html` (Outlook) |
| פונט | Heebo, נפילה Arial / Helvetica |
| צהוב CTA | `#fed700` על טקסט `#1a1a1a`. לא `#f5c518` |
| כסף | אגורות ב-payload, תצוגה בלבד דרך פורמט שקלים. אין חלוקה ב-float בנוסח |
| QR | אסור `data:` URI. קוד קריא + קישור ל-
`/coupon/{id}` |
| כפילות | הזמנת קופון: רק
`voucher_issued`.
לא גם
`order_paid` |
| 30א | מייל טרנזקציוני לא תלוי בהסכמת דיוור. `welcome` בלי מבצע ובלי "עוד דילים" |

מעטפת:

```
KenyonExpress
{גוף}
קיבלת את המייל הזה כי {סיבה}.
```

CTA: כפתור צהוב, יישור מרכז, משקל 700.

kinds שכבר נבנים ב-

```
src/lib/email/notifications.ts
src/lib/email/voucher-email.ts
```

מסומנים "בקוד". שני kinds בבריף שעוד אין להם builder:
`order_shipped`,
`account_deleted`.

## order_paid (בקוד)

נשלח רק להזמנה **בלי** שוברים. אישור קבלה, לא הבטחת משלוח.

**נושא**

```
ההזמנה שלך התקבלה · {ref}
```

**גוף (טקסט)**

```
שלום {שם},

התשלום התקבל וההזמנה שלך נקלטה.

מספר הזמנה: {ref}
סך הכל שולם באתר: {סכום}

לפרטי ההזמנה: {אתר}/account/orders
לקבלה: {אתר}/account/orders/{id}/invoice
```

בלי שם: `שלום,`. קישור הקבלה פנימי (בדיקת בעלות בלחיצה), לא URL של חברת האשראי.

**כותרת ב-HTML:** התשלום התקבל.

**כפתור:** לפרטי ההזמנה.

**פוטר:** קיבלת את המייל הזה כי ביצעת רכישה ב-KenyonExpress.

## voucher_issued (בקוד)

**נושא**

קופון אחד:

```
הקופון שלך מוכן: {שם המוצר}
```

יותר מאחד:

```
{N} קופונים מוכנים לך ב-KenyonExpress
```

**גוף (טקסט), לכל שובר**

```
שלום {שם},

הקופון שלך מוכן לשימוש.

{שם המוצר} · {שם הספק}
קוד: {קוד מקובץ}
שולם באתר: {coupon_price}
לתשלום בבית העסק: {remaining_due}
בתוקף עד: {תאריך he-IL}
הצגת הקופון: {אתר}/coupon/{id}
```

סדר הסכומים חובה: שולם באתר, אחר כך יתרה בעסק, אחר כך (משני) מחיר מלא אם מוצגים שלושה. אסור להבטיח לספק שחרור כסף לפני מימוש.

**כפתור:** הצגת הקופון ו-QR.

**פוטר:** קיבלת את המייל הזה כי רכשת קופון ב-KenyonExpress.

## voucher_expiring (בקוד)

נשלח רק עם מספר ימים או תאריך. בלי דדליין: לא לשלוח.

**נושא**

יום אחד:

```
{שם המוצר} פג מחר
```

אחרת:

```
{שם המוצר} פג {בעוד יומיים | בעוד N ימים}
```

**גוף**

```
שלום,

{שם המוצר} ב{שם הספק} עדיין לא מומש, והתוקף שלו נגמר {מחר | בעוד יומיים | בעוד N ימים}.
תאריך התפוגה: {תאריך}.

הקופונים שלך:
{אתר}/account/coupons
```

אין "שווה לנצל" כמבצע. זו תזכורת תוקף על משהו שכבר נרכש.

**כפתור:** לצפייה בקופון.

**פוטר:** קיבלת את המייל הזה כי יש לך קופון פעיל ב-KenyonExpress.

## order_shipped (אין builder ב-outbox)

מימוש עתידי למשלוח פיזי. בשיגור הנוכחי אין פיזי. הנוסח מוכן כדי לא לכתוב שיווק כשייפתח kind.

**נושא**

```
ההזמנה {ref} יצאה למשלוח
```

**גוף**

```
שלום {שם},

ההזמנה {ref} נמסרה למשלוח.

מספר מעקב: {tracking}   (אם אין: השורה נמחקת, לא נכתב "בקרוב")
ספק: {שם הספק}

למעקב:
{אתר}/account/orders/{id}
```

אסור "המשלוח בדרך!" בלי מספר או בלי סטטוס
`shipped`
בשורת הפריט. אסור להבטיח תאריך דלת שלא נמסר מהספק.

**כפתור:** להזמנה שלי.

**פוטר:** קיבלת את המייל הזה כי הזמנה שלך סומנה כנשלחה ב-KenyonExpress.

## refund_completed (בקוד)

רק אחרי שהכסף זז. סכום ≤0: לא לשלוח.

**נושא**

```
הזיכוי שלך בוצע: {סכום}
```

**גוף, זיכוי כרטיס**

```
שלום,

זיכינו את הכרטיס שלך ב-{סכום} על הזמנה {ref}.
נוכו דמי ביטול בסך {דמי ביטול} לפי התקנון.   (רק אם >0)

הזיכוי מבוצע מול חברת האשראי, וההופעה בפועל בדף החשבון תלויה במנפיק הכרטיס.

ההזמנות שלך:
{אתר}/account/orders
```

**גוף, ביטול באותו יום סליקה (`cancel_only`)**

```
שלום,

ביטלנו את החיוב על הזמנה {ref}. הסכום לא ייגבה כלל.
```

לא לכתוב "זוכה" כשלא היה חיוב בחשבון.

**כפתור:** להזמנות שלי.

**פוטר:** קיבלת את המייל הזה כי בוצע זיכוי על הזמנה שלך ב-KenyonExpress.

החזר **לארנק** אינו kind הזה. ראה
`cashback_credited`
רק לקאשבק רכישה. החזר יתרה לארנק, אם יוחלט, צריך kind נפרד או משפט מפורש "הסכום הופקד בארנק" בלי המילה קאשבק.

## welcome (בקוד)

פעם אחת למזהה משתמש (`welcome:{user id}`).

**נושא**

```
ברוכים הבאים ל-KenyonExpress
```

**גוף**

```
שלום {שם},

החשבון שלך מוכן. מכאן אפשר לקנות קופונים ומוצרים מעסקים בישראל,
והקופונים שתקנו יחכו לך באזור האישי עם קוד לסריקה בבית העסק.

הקופונים שלי: {אתר}/account/coupons
ההזמנות שלי: {אתר}/account/orders
```

אסור: קוד קופון, אחוז הנחה, "ואלה עוד דילים", הרשמה לניוזלטר כברירת מחדל.

**כפתור:** לקופונים שלי.

**פוטר:** קיבלת את המייל הזה כי נפתח חשבון ב-KenyonExpress עם כתובת המייל הזאת.

## account_deleted (אין builder ב-outbox)

נשלח אחרי שהמחיקה **הושלמה**, לא אחרי לחיצה על "התחל מחיקה".

**נושא**

```
החשבון שלך ב-KenyonExpress נמחק
```

**גוף**

```
שלום,

החשבון המחובר לכתובת הזאת נמחק לפי בקשתך.

קופונים שטרם מומשו והזמנות ששולמו נשמרים כנדרש בחוק, ולא דרך החשבון שנמחק.
פניות: {אתר}/contact

אם לא ביקשת את המחיקה, פנה אלינו מיד.
```

אסור לבקש "חזור אלינו עם 10%". אסור לצרף קישור הרשמה כ-CTA צהוב ראשי. אין כפתור קנייה.

**פוטר:** קיבלת את המייל הזה כי נמחקה הרשמה ב-KenyonExpress לכתובת הזאת.

## cashback_credited (בקוד)

רק אחרי
`fn_wallet_transfer`.
סכום ≤0: לא לשלוח.

**נושא**

```
נכנס לך קאשבק של {סכום}
```

סכום בלי `.00` כשאין אגורות (`₪25`, לא `₪25.00`).

**גוף**

```
שלום,

נכנס לך קאשבק של {סכום}{ על הזמנה {ref} אם יש}.
הסכום נמצא בארנק שלך ואפשר להשתמש בו בקנייה הבאה.

הארנק:
{אתר}/account/wallet
```

לא לקרוא לזה החזר. לא לקרוא לזה מתנה שיווקית.

**כפתור:** לארנק שלי.

**פוטר:** קיבלת את המייל הזה כי זוכה קאשבק בארנק KenyonExpress.

## בדיקת RTL לפני שליחה

1. Gmail ו-Outlook: הסכום ₪ משמאל לספרות, לא הפוך.
2. הקוד בגופן חד-רוחב, `dir="ltr"` על שורת הקוד בלבד.
3. אין תמונה שבורה במקום QR.
4. כפתור צהוב לא נחתך ב-380px רוחב תצוגת מייל.
