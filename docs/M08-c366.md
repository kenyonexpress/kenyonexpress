## The local robots.txt timeout

In c365 one local run failed `robots-txt` when the proxy's 5-minute redirect table expired and the request waited for a reload from Supabase. It did not happen here, and this cycle is not evidence either way: the local server's first request was at about 09:04:00Z and the last local run ended at 09:09:09Z, so at most the tail of the last run fell after the 5-minute expiry. No live run failed `robots-txt` (0 of 12, as in c365).
