# רנבוק אדמין יומי ושבועי

Status: DRAFT · docs only  
Audience: `admin` (בעלים / תפעול פלטפורמה)  
Admin UI: `https://kenyonexpress.co.il/admin`  
Timezone: `Asia/Jerusalem`  
Money: אגורות ב-DB, תצוגה ₪. אין float.

מסמך זה הוא שגרה תפעולית. מדיניות כסף: `docs/BUSINESS-MODEL.md`, `docs/legal/RETURNS-HE.md`. תמיכת לקוח: `docs/CUSTOMER-SUPPORT-PLAYBOOK.md`, `docs/support/CUSTOMER-FAQ-HE.md`. KPI: `docs/ARCHITECTURE-ANALYTICS-KPI.md`. אין `UPDATE` ידני על הזמנות, תשלומים או שוברים.

---

## 0. כללי ברזל

1. אדמין רואה נתוני פלטפורמה. ספק לא רואה GMV / עמלה / קאשבק של אחרים.
2. החזר רק לסכום שנגבה באתר, דרך מסלול refund בקוד, לא SQL.
3. באג כסף או חיוב בלי שובר: כיבוי קופה לפי `docs/RUNBOOK-OPS.md` לפני ויכוח עם לקוח.
4. אין PAN בטיקטים. מזהים: אימייל, מספר הזמנה, קוד שובר (10 תווים).
5. soft-launch: קטלוג ציבורי = קופון בלבד עד החלטת בעלים.
6. שעון דוחות: יום עסקים בירושלים, לא UTC גולמי בלי המרה.

## 1. שגרה יומית (כל בוקר עסקים, ~20–40 דקות)

סדר קבוע. לא לדלג על תור החזרים גם אם הקטלוג "שקט".

### 1.1 תורנות בריאות (2 דקות)

- [ ] האתר נפתח: בית, קטגוריה, מוצר קופון, `/cart`, `/checkout`.
- [ ] התחברות Google עובדת (חשבון בדיקה).
- [ ] `/scan` נטען (בלי סריקה אמיתית אם אין שובר בדיקה).
- [ ] אין באנר שגיאה גלוי בבית.
- [ ] אם CardCom / webhook חשוד: לא "לתקן" הזמנה ידנית. ראו `docs/RUNBOOK-OPS.md`.

### 1.2 מודרציה: ביקורות ודיווחים

- [ ] ביקורות ממתינות: לאשר / לדחות לפי `docs/ARCHITECTURE-REVIEWS.md`. דחייה: תוכן פוגע, ספאם, PII, דירוג בלי קנייה כשהמדיניות דורשת.
- [ ] דיווחי לקוח על מוצר / ספק: תיעוד + האם להסתיר מוצר (`active=false`) עד בדיקה.
- [ ] תמונות מוצר חדשות שנראות כזכויות יוצרים / פוגעניות: הסתרה עד תיקון מעלה.

### 1.3 תור החזרים וביטולים

- [ ] מיילים ל-`info@kenyonexpress.co.il` עם נושא ביטול / החזר / "לא קוד".
- [ ] לכל פנייה: סטטוס שובר (`issued` / `redeemed` / `expired` / `refunded`) + `orders.paid_at`.
- [ ] קופון לא מומש בתוך 14 יום מיום העסקה מרחוק: מסלול ביטול רגיל לפי `docs/legal/RETURNS-HE.md`.
- [ ] קופון מומש: אין ביטול רגיל. חריג רק בעלים + ספק בכתב.
- [ ] אחרי אישור החזר: הלקוח רואה זיכוי כרטיס עד 14 ימי עסקים, או ארנק אם בחר. לא להבטיח "מיידי".
- [ ] דמי ביטול: בשיגור לא גובים בלי אישור בעלים מפורש.

קריאה בלבד (דוגמה, לא הרצה עיוורת בפרודקשן בלי הקשר):

```sql
-- הזמנות ששולמו אתמול (שעון ירושלים) בלי שובר issued
-- שלד בלבד; להתאים לעמודות בפועל לפני שימוש
SELECT o.id, o.paid_at, o.total_agorot
FROM public.orders o
WHERE o.paid_at IS NOT NULL
  AND o.paid_at >= (CURRENT_DATE AT TIME ZONE 'Asia/Jerusalem') - INTERVAL '1 day'
ORDER BY o.paid_at DESC;
```

### 1.4 אישורי מעלה תוכן (`content_uploader`)

- [ ] טיוטות ממתינות ב-`/admin` (או מסך המעלה): כותרת, מחיר אגורות, תמונה 1:1, קטגוריה, ספק.
- [ ] דחייה עם סיבה קצרה בעברית (ראו `docs/support/UPLOADER-GUIDE-HE.md`).
- [ ] פרסום רק אחרי אישור אנושי. סוכן AI לא מפרסם לבד (`docs/ARCHITECTURE-AI-AGENTS.md`).

### 1.5 קמפיינים וקופונים שיווקיים

- [ ] קופון אתר עם תאריך תפוגה היום: לוודא שלא מפרסמים אחוז אחרי פקיעה.
- [ ] באנר בית / קרוסלה: לינק חי, מוצר `active`, מחיר תואם.
- [ ] WhatsApp / אימייל שיווקי: רק למי שנתן opt-in (30א). אין שיגור המוני בלי רשימה מאושרת.

### 1.6 KPI בוקר (מבט מהיר)

מקור אמת: `orders.paid_at IS NOT NULL`. לא ספירת redirect.

| מדד | מה לראות |
|---|---|
| הזמנות ששולמו אתמול | count |
| GMV באתר (אגורות) | סכום שנגבה באתר |
| החזרים פתוחים | מספר טיקטים לא סגורים |
| שגיאות סריקה | אם יש לוג / פניות |
| Redeem אתמול | שוברים `redeemed` |

פירוט נוסחאות: `docs/growth/KPI-DASHBOARD-SPEC.md`.

### 1.7 סוף יום (5 דקות)

- [ ] אין טיקט כסף פתוח בלי בעלים.
- [ ] מוצר שבור / 404 מתועד להסתרה.
- [ ] אם נדרש כיבוי קופה: תועד ב-`docs/RUNBOOK-OPS.md` ולא ב-Slack בלבד.

## 2. שגרה שבועית (יום קבוע, ~45–90 דקות)

### 2.1 Payouts וספקים

- [ ] דוחות ספק: עמלות / יתרות פיזי לפי מודל (קופון: אין payout על מקדמת האתר).
- [ ] מחלוקות ספק-לקוח: רק אחרי ראיות (צילום קבלה, זמן סריקה).
- [ ] ספק עם הרבה כשלונות סריקה: הדרכה + בדיקת הרשאות צוות.
- [ ] לא "להעביר כסף ידנית" מחוץ למסלול המערכת.

### 2.2 קטלוג ואיכות

- [ ] מוצרים ללא תמונה / תמונת placeholder: תור למעלה.
- [ ] כפילויות slug / אותו עסק בשתי כרטיסיות: מיזוג או הסתרה.
- [ ] קטגוריות ריקות בבית: הסתרה או מילוי (לא דף 404 שבור).
- [ ] ביקורות: יחס דחייה חריג = לבדוק ספאם.

### 2.3 מעלה תוכן ו-AI

- [ ] כמה טיוטות אושרו / נדחו השבוע.
- [ ] דחיות חוזרות מאותו מעלה: שיחת הדרכה, לא פרסום "כדי לזוז".
- [ ] שימוש ב-AI: לוודא שלא פורסמו הבטחות אסורות (`docs/product/PRODUCT-COPY-GUIDE.md`).

### 2.4 קמפיינים

- [ ] לוח השבוע הבא: באנר, קופון אתר, תזכורות תפוגה (טריגר עסקי, לא 30א אם זו הודעת עסקה).
- [ ] קריאייטיב רשתות: תואם `docs/marketing/SOCIAL-LAUNCH-HE.md` (בלי "הכי זול בארץ").
- [ ] UTM: מקורות מתועדים לדוח השבועי.

### 2.5 דוח KPI שבועי לבעלים

תבנית קבועה (טקסט / גיליון). לא לייצא PII.

1. הזמנות ששולמו, GMV באתר, AOV (אגורות → ₪ לתצוגה).
2. הכנסת פלטפורמה: קופון = שולם באתר; פיזי = עמלה מ-`platform_percent` בצילום שורה.
3. Funnel: `view_item` → `add_to_cart` → `begin_checkout` → `purchase`.
4. Redeem rate, expiry rate, זמן חציוני למימוש.
5. החזרים: מספר וסכום (רק אתר).
6. שגיאות סריקה / פניות תמיכה לפי נושא.
7. קטלוג: מוצרים פעילים, טיוטות ממתינות.

שעון: שבוע שמתחיל ביום ראשון 00:00 ירושלים, אלא אם הוחלט אחרת ותועד.
