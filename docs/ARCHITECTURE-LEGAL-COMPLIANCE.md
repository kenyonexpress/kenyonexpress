## 1. חוק הגנת הצרכן (מכר מרחוק)

| חובה | יישום במוצר |
|---|---|
| גילוי מוקדם | בלוק "פרטי העסקה" ב-PDP: עוסק, ח.פ, מחיר כולל מע"מ, זכות ביטול |
| מסמך בכתב | מייל טרנזקציוני ב-paid / עם הקופון |
| זכות ביטול 14 יום | מנוע ביטולים בשרת; לקופון מ-`paid_at` (כל עוד לא מומש / לא חל פטור) |
| דמי ביטול | `min(5% מסכום העסקה הרלוונטי, 100 ₪)` באגורות; פגם → 0 |
| החזר תוך 14 יום | כרטיס→Cardcom refund; ארנק→זיכוי ארנק פנימי |
| ביטול מקוון | `/cancel` + אזור אישי |

### 1.1 חישוב דמי ביטול

```text
fee_agorot = min(floor(amount_agorot * 5 / 100), 10000)
אם reason ∈ {defect, non_delivery, non_conformity}: fee_agorot = 0
החזר = amount_agorot - fee_agorot
```

הסכום הרלוונטי לקופון = מה ששולם באתר (לא יתרת העסק שלא שולמה בפלטפורמה).

### 1.2 פטורים / חריגים

שירותי בילוי/אירוח וכו' לפי 14ג(ד) כשחל חלון קצר לפני מועד השירות: מסומן ב-`cancellation_exempt` + הסבר בעברית ב-PDP.

## 2. תוקף שוברים

| כלל | פירוט |
|---|---|
| חובה | `expires_at` בכל voucher |
| תזכורת | `coupon_expiry_48h` (ניתן לכיבוי) |
| פקיעה | סטטוס `expired`; מייל `coupon_expired`; Wallet void |
| הארכה | רק admin + audit; לא אוטומטית |
| אחרי מימוש | אין הארכה; אין החזר אוטומטי רק כי "לא נוח" |

גילוי ב-PDP ובמייל: תאריך תוקף בעברית (`he-IL`).

## 3. תקנות נגישות ישראליות

| דרישה | יישום |
|---|---|
| תקנות התאמות נגישות לשירות | אתר ציבורי נגיש |
| ת"י 5568 / WCAG 2.x AA | יעד בדיקות + CI a11y smoke |
| RTL עברית | `lang=he` `dir=rtl` מהמסמך, לא רק אחרי JS |
| הצהרת נגישות | `/accessibility` + קישור ב-footer |
| ניגודיות / מקלדת / תוויות | חובה על CTA וטפסים |

אין להסתמך על תוסף נגישות כתחליף ל-HTML סמנטי נכון.
