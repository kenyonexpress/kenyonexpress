Root cause: the CSP `script-src` built in `src/lib/security/frame-policy.ts` has no `'unsafe-eval'`, and React dev mode calls eval() to rebuild server callstacks, so it logs one console error on every page.

## Fix

In `src/lib/security/frame-policy.ts` `baseDirectives()`, add `'unsafe-eval'` to `script-src` only when `NODE_ENV === 'development'`. Production CSP is unchanged because production bundles never call eval().


```
script-src 'self' 'unsafe-inline' 'unsafe-eval' https://challenges.cloudflare.com
```
