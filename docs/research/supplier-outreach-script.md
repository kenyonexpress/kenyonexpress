# תסריט פנייה לבעלי עסקים

מותאם למודל של קניון אקספרס: הלקוח קונה קופון באתר, מגיע לעסק, העסק סורק את השובר (QR) בפורטל הספקים, רואה הכל בדשבורד, ומקבל תשלום לפי הסיכום. העמלה דינמית פר מוצר.

## הודעת WhatsApp ראשונה

לספק חדש:

```
היי [שם], מדבר אופיר מקניון אקספרס (kenyonexpress.co.il).
אנחנו אתר דילים ישראלי, ואני בונה עכשיו את עמוד ההשקה שלנו.
אני מחפש [מסעדה/ספא/מספרה] אחת באזור [עיר] שתהיה דיל הדגל של הקטגוריה.
בלי עלות הצטרפות, בלי התחייבות, אתם משלמים רק עמלה על מה שנמכר בפועל.
יש לך 5 דקות לשיחה השבוע?
```

לספק שעבד עם האתר הישן:

```
היי [שם], אופיר מקניון אקספרס.
העלינו גרסה חדשה לגמרי של האתר, מהירה ועם אזור אישי לעסקים:
אתם סורקים את השובר בטלפון, רואים כל מכירה בדשבורד, והכסף מתחשבן אוטומטית.
הדיל שלכם ([תיאור הדיל הישן]) עבד יפה, רוצה שנחזיר אותו לעמוד הראשי של ההשקה?
```

## מענה להתנגדויות

**"כמה זה עולה?"**

```
כלום מראש. אין דמי הקמה ואין מנוי.
אנחנו גובים עמלה רק על קופון שנמכר בפועל, באחוז שנסגור יחד לפי סוג הדיל.
לא נמכר כלום? לא שילמתם כלום.
```

**"מי משלם, ואיך אני יודע שלא מרמים אותי?"**

```
הלקוח משלם באתר בכרטיס אשראי (סליקה מאובטחת של Cardcom).
כל שובר הוא חד פעמי עם QR: אתם סורקים אותו אצלכם בעסק ברגע שהלקוח מגיע,
והוא נשרף במערכת באותה שנייה. אי אפשר לממש פעמיים.
בדשבורד שלכם רואים בזמן אמת כמה נמכר, כמה מומש וכמה מגיע לכם.
```

**"מתי אני מקבל את הכסף?"**

```
ההתחשבנות לפי מימושים: שובר שנסרק אצלכם נכנס לדוח התשלומים שלכם מיידית,
והתשלום עובר בהעברה במחזור קבוע שנסגר בהסכם (לרוב שוטף קצר).
הכל שקוף בפורטל, כל שורה עם תאריך, שובר וסכום.
```

**"אני לא רוצה למכור בזול / זה יוריד לי את המותג"**

```
הדיל הוא כלי שיווק, לא מחירון חדש: כמות מוגבלת, לתקופה מוגבלת.
לקוח שמגיע עם קופון משלם אצלכם גם על תוספות, וחוזר אחר כך במחיר מלא.
אתם קובעים את הכמות ואת התנאים (ימים, שעות, בתיאום מראש) ואנחנו אוכפים אותם בשובר.
```

**"אין לי זמן להתעסק עם זה"**

```
כל מה שצריך מכם: אישור על נוסח הדיל ומחיר, ולסרוק שובר כשלקוח מגיע.
את הכל אנחנו מקימים: עמוד, צילומים אם צריך, תנאים.
ההקמה מוכנה תוך יום עבודה.
```

## סגירה

```
בוא נעשה את זה פשוט: נריץ דיל אחד לניסיון, [הצעת הדיל הספציפית מ-launch-deals-final],
בכמות של [30] קופונים. אם זה עובד לשניינו, ממשיכים ומרחיבים.
אני שולח לך עכשיו נוסח לאישור, ומחר אתם באוויר. סוגרים?
```

אחרי אישור: לשלוח נוסח דיל + מחיר + כמות + תוקף בהודעה אחת לאישור בכתב, ולהקים במערכת רק אחרי "מאושר".
