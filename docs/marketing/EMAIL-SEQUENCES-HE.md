# סדרות מייל אוטומטיות

תאריך: 2026-09-02.
עותק ללקוח בעברית, RTL. שמות kinds באנגלית.

מעטפת: KenyonExpress, `dir="rtl"`, CTA צהוב `#fed700` על טקסט `#1a1a1a`. כסף באגורות ב-payload, תצוגה בשקלים. אין QR כ-`data:` URI. אין float בנוסח.

30א: תפעולי יוצא בלי הסכמת דיוור. שיווקי רק ל-opt-in. הסרה בכל שיווקי.

הזמנת קופון: לא שולחים גם `order_paid` וגם `voucher_issued`.

---

## סדרה 1: welcome (3 מיילים)

Kind בסיס: `welcome`. מייל 1 תפעולי, פעם אחת למשתמש (`welcome:{user id}`). מיילים 2–3 שיווקיים, opt-in, ורק אם אין הזמנה `paid`.

### 1.1 יום 0: החשבון מוכן

**נושא**

```
ברוכים הבאים ל-KenyonExpress
```

**גוף**

```
שלום {שם},

החשבון שלך מוכן. מכאן אפשר לקנות קופונים מעסקים בישראל,
והקופונים שתקנו יחכו באזור האישי עם קוד לסריקה בבית העסק.

משלמים באתר רק את מחיר הקופון. את היתרה, אם יש, משלמים בבית העסק אחרי סריקה.

הקופונים שלי: {אתר}/account/coupons
ההזמנות שלי: {אתר}/account/orders
```

כפתור: לקופונים שלי.
פוטר: קיבלת את המייל כי נפתח חשבון ב-KenyonExpress עם הכתובת הזאת.
אסור: קוד קופון, אחוז הנחה, "ואלה עוד דילים".

### 1.2 יום 3: איך מממשים (opt-in)

**נושא**

```
איך מממשים קופון בקניון Express
```

**גוף**

```
שלום {שם},

קצר: בוחרים דיל, משלמים באתר את מחיר הקופון, מציגים QR בבית העסק,
ומשלימים יתרה בקופה רק אם היא כתובה בעמוד הדיל.

הקוד חד פעמי. צילום מסך לא מקנה מימוש שני.

לקטלוג: {אתר}/
```

כפתור: לקטלוג.
לא לשלוח אם כבר יש קופון פעיל.

### 1.3 יום 7: דיל אחד חי (opt-in)

**נושא**

```
דיל אחד להתחיל איתו: {שם הדיל}
```

**גוף**

```
שלום {שם},

{שם הדיל} אצל {שם הספק} ב{עיר}.
מחיר הקופון באתר: {coupon_price}.
יתרה בבית העסק: {יתרה}.

הקישור: {אתר}/product/{slug}
```

רק דיל `active` עם ספק מלא. בלי "הכי זול". בלי קטגוריה ריקה.

## סדרה 2: abandoned cart (2 מיילים)

שיווקי, opt-in. טריגר: עגלה עם פריט, אין `paid`, עברו שעתיים. עוצרים אם שילם, אם רוקן, או אם המלאי ירד.

אין לכתוב שהחיוב עבר.

### 2.1 אחרי שעתיים

**נושא**

```
העגלה שלך בקניון Express ממתינה
```

**גוף**

```
שלום {שם},

נשאר בסל: {שם המוצר} אצל {שם הספק}.
מחיר הקופון באתר: {coupon_price}.
יתרה בבית העסק במעמד המימוש: {יתרה}.

להשלמה: {אתר}/cart
```

כפתור: לעגלה.

### 2.2 אחרי 24 שעות

**נושא**

```
{שם המוצר} עדיין בסל
```

**גוף**

```
שלום {שם},

הדיל בעגלה עדיין פעיל לפי המלאי הנוכחי, בלי הבטחת מחיר ישן אם השתנה בקופה.
המחיר המחייב הוא זה שבמסך התשלום.

{אתר}/cart
```

אין קופון הנחה על נטישה בשיגור. אין ספאם אחרי מייל 2.

## סדרה 3: voucher expiring (2 מיילים)

תפעולי. רק עם תאריך אמיתי. בלי דדליין: לא לשלוח. kind: `voucher_expiring`.

### 3.1 שבעה ימים לפני פקיעה

**נושא**

```
{שם המוצר} פג בעוד 7 ימים
```

**גוף**

```
שלום,

{שם המוצר} ב{שם הספק} עדיין לא מומש.
תאריך התפוגה: {תאריך}.

הקופונים שלך: {אתר}/account/coupons
הצגת הקופון: {אתר}/coupon/{id}
```

אין "שווה לנצל" כמבצע. זו תזכורת תוקף על משהו שכבר נרכש.

### 3.2 יום לפני פקיעה

**נושא**

```
{שם המוצר} פג מחר
```

**גוף**

```
שלום,

{שם המוצר} ב{שם הספק} פג מחר, {תאריך}.
אחרי התאריך הקוד לא ייסרק.

{אתר}/coupon/{id}
```

אם כבר `redeemed`: לא יוצא.

## סדרה 4: בקשת חוות דעת אחרי מימוש

מייל אחד. 24 שעות אחרי
`redeemed`.
שיווקי קל: מותר בלי מבצע. אם אין opt-in, שולחים גרסה תפעולית קצרה בלי דיל אחר.

**נושא**

```
איך היה אצל {שם הספק}?
```

**גוף**

```
שלום {שם},

הקופון {שם המוצר} סומן כמומש ב{תאריך}.
אם החוויה בבית העסק הייתה שונה ממה שכתוב בדיל, כתבו לנו: {אתר}/contact

אין בזה החזר אוטומטי. טיב השירות הוא באחריות בית העסק. אנחנו מסייעים בבירור.

לא לדרג בכוכבים מזויפים. תשובה חופשית מספיקה.
```

כפתור: יצירת קשר.
אסור: בקשת 5 כוכבים, הנחה תמורת ביקורת, הפניית Google ממולאת.

## סדרה 5: win-back אחרי 60 יום

מייל אחד. 60 יום בלי `paid`. שיווקי, opt-in. עוצר אם רכש בינתיים.

**נושא**

```
חזרנו. יש דילים חדשים בקניון Express
```

**גוף**

```
שלום {שם},

עברו שישים יום בלי רכישה אצלנו.
אם זה הזמן, הנה דיל פעיל אחד, לא רשימה:

{שם הדיל} אצל {שם הספק}.
מחיר קופון באתר: {coupon_price}. יתרה בעסק: {יתרה}.
{אתר}/product/{slug}

הסרה מדיוור: {קישור הסרה}
```

בלי "התגעגענו" עם קופון מתנה. בלי קטגוריה ריקה. דיל `active` בלבד.

## סדרה 6: cashback credited

מייל אחד. תפעולי. אחרי
`fn_wallet_transfer`
בלבד. סכום ≤0: לא לשלוח. kind: `cashback_credited`.

**נושא**

```
נכנס לך קאשבק של {סכום}
```

סכום בלי `.00` כשאין אגורות (`₪25`, לא `₪25.00`).

**גוף**

```
שלום,

נכנס לך קאשבק של {סכום}{ על הזמנה {ref} אם יש}.
הסכום בארנק שלך באתר. אפשר להשתמש בו בקנייה הבאה.
הארנק לא ניתן למשיכה, להעברה או להמרה למזומן.

הארנק: {אתר}/account/wallet
```

לא לקרוא לזה החזר. לא מתנה שיווקית. לא כסף לכרטיס.

כפתור: לארנק שלי.
פוטר: קיבלת את המייל כי זוכה קאשבק בארנק KenyonExpress.

## RTL לפני שליחה

1. ₪ משמאל לספרות.
2. קוד קופון בגופן חד-רוחב,
   `dir="ltr"`
   על השורה בלבד.
3. כפתור צהוב לא נחתך ברוחב 380.
4. אין תמונה שבורה במקום QR.
