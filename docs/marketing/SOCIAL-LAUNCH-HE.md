# פוסטים לחודש ההשקה

Status: DRAFT · docs only  
ערוצים: פייסבוק, אינסטגרם (פיד / סטורי קצר), סטטוס וואטסאפ עסקי.  
T0 = יום שהדומיין החי מגיש את האתר החדש. חודש = T0 עד T+29.  
מודל: **קופון קודם.** משלמים באתר את מחיר הקופון. יתרה, אם כתובה בדיל, בבית העסק אחרי סריקת QR.

30א: פרסום בעמוד ציבורי מותר. שליחה אישית / שידור רשימה: רק opt-in. סטטוס וואטסאפ: מעגל מבוקר, לא ייבוא אנשי קשר.

אסור בכל פוסט: "הכי זול בארץ / בישראל / בעיר", Escrow / נאמן, מלאי "נשארו 2" בלי נתון, "תשלום מלא באתר" על קופון עם יתרה, "החזר מיידי" לכרטיס, העתקת מתחרה, דיל `physical` בשיגור, מחיר float, הבטחת תור בלי הספק.

מחיר בפוסט = מחיר קופון באתר + יתרה אם יש. קישור PDP או בית. UTM: `utm_source=facebook|instagram|whatsapp&utm_medium=organic&utm_campaign=launch_m1`.

CTA קבועים לבחירה: `לדיל באתר` · `לקטלוג` · `איך מממשים` · `הקופונים שלי`.

פורמט כל רשומה: יום משוער, ערוץ מועדף, הוק, גוף, CTA, נכס ויזואלי.
