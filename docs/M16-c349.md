## Defect found and fixed

The sample has `"highPrice": "1000.00"` on a plain `Offer`. schema.org defines `highPrice` on `AggregateOffer` only, so validators flag it on every discounted product.
`src/lib/seo/json-ld.ts` now puts the sticker price in `priceSpecification` as a `UnitPriceSpecification` with `priceType: https://schema.org/StrikethroughPrice`, which is Google's documented strikethrough encoding. `price` (what is charged) is unchanged. Tests updated in `src/lib/seo/json-ld.test.ts`.

The fix reaches production on the next deploy. The pass above is the presence gate, measured on what is live now.
