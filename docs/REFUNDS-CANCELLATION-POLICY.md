## 1. מתי ניתן לבטל

| מצב | קופון | פיזי |
|---|---|---|
| תוך 14 יום מ-`paid_at`, טרם מימוש / טרם משלוח מהותי | כן (בכפוף לחוק) | כן (בכפוף לחוק ופטורים) |
| אחרי מימוש (`redeemed`) | לא אוטומטי; מחלוקת מול ספק | לא רלוונטי לקופון |
| אחרי משלוח / איסוף | לא רלוונטי | לפי דין (פגם / אי-התאמה / פטורים) |
| פגם / אי-אספקה באחריות הפלטפורמה/ספק | דמי ביטול 0 | דמי ביטול 0 |
| אותו יום עסקים לפני שידור מלא | ביטול עסקה אפשרי לפי Cardcom | כמו קופון |

פטורים סטטוטוריים (למשל מוצרים מסוימים, הזמנה אישית): **[דורש עו״ד]** לניסוח מדויק בעמוד המדיניות.

## 2. חישוב דמי ביטול והחזר

```text
amount_agorot = paid_on_site_agorot   # לקופון: מחיר האתר בלבד
fee_agorot    = min(floor(amount_agorot * 5 / 100), 10000)
refund_agorot = amount_agorot - fee_agorot   # אם חלים דמי ביטול
# פגם / אי-אספקה → fee_agorot = 0
```

החזר תוך **14 יום** ממועד אישור הביטול (יעד מוצר; **[דורש עו״ד]** מול ניסוח ללקוח).

---

## 3. זרימה תפעולית

```text
בקשת ביטול (/cancel או תמיכה)
  → בדיקת זכאות (סטטוס voucher / משלוח / חלון 14 יום)
  → אם מאושר:
       freeze קופון אם issued
       Cardcom refund / void לפי מצב
       status voucher → refunded (אם רלוונטי)
       ledger / settlement: supplier_debit אם כבר נזקף לספק פיזי
  → מייל אישור ביטול
```

אין refund בלי audit. אין לבקש מהלקוח CVV / PAN מלא.
