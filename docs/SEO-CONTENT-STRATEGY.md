## 3. כללי כתיבה

1. עברית טבעית; כותרת אחת ראשית לדף.  
2. בכל דף דיל: מחיר באתר + יתרה בעסק + face אם רלוונטי.  
3. אסור: נאמן, Escrow, הבטחות מלאי שקריות.  
4. כותרות title ≤ ~60 תווים; meta description ייחודית.  
5. קישורים פנימיים: בית ↔ קטגוריה ↔ PDP ↔ FAQ.  
6. תמונות עם alt בעברית תיאורי (בלי stuffing).

פירוט ניסוח דיל: `CONTENT-PLAYBOOK.md`.

## 4. מילות מפתח (אשכולות)

| אשכול | דוגמאות |
|---|---|
| מותג | קניון express, kenyonexpress |
| קופון | קופון מסעדה, דיל ארוחה זוגית |
| קטגוריה | סושי קופון, בראנץ זוגי |
| עיר | קופונים תל אביב, דילים חיפה |
| כוונה | איך מממשים קופון מסעדה |

לא לירות על מילת מפתח אחת מעשרה דפים כמעט זהים (cannibalization).

## 5. טכני (תמצית)

| נושא | כלל |
|---|---|
| Index | רק עמודים עם תוכן ייחודי + דילים |
| Canonical | לפי SEO-PERFORMANCE |
